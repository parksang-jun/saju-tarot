## 내부 기록

- 주의: 이달의 운세 탭과 날짜별 달력은 1.4에서 없앴다

- 보상형 광고(AdMob, `@capacitor-community/admob` 8.4.2). 지금은 구글 테스트 ID. 실제 ID로 바꾸는 절차와 플레이 콘솔 선언 변경은 `docs/RELEASE.md`의 "보상형 광고" 참고
- 광고를 불러오지 못하면 사용자를 막지 않고 연다. 광고를 중간에 닫으면 열리지 않는다
- 사주를 연(결제한) 사람은 광고 없이 본다
- 단계 표시: 무료(초록), 광고 보고 보기(파랑), 유료 990원(금색)
