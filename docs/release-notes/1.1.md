# 등불사주 1.1 (versionCode 2)

## 플레이 콘솔 "출시 노트"에 붙여 넣을 내용

```
<ko-KR>
· 궁합을 겉궁합, 속궁합, 살림 궁합으로 나눠 아홉 항목으로 자세히 봅니다. 몸과 정, 마음과 대화, 돈, 다툼과 화해 항목이 새로 생겼습니다
· 관상에 "이렇게 바뀌면 좋아집니다"가 생겼습니다. 표정과 습관을 바꾸면 총점과 운이 얼마나 오르는지 보여 줍니다
</ko-KR>
```

## 내부 기록

- 궁합: 항목 5개 → 연인·부부 9개, 친구·동료 8개. 묶음별 점수(겉/속/살림) 타일 추가. 속궁합의 "몸과 정"은 일지 관계, 일간 음양, 사주의 온도(조후)로 계산하며 연인·부부에서만 보인다. 문구는 콘텐츠 등급 설문 답변(성적 콘텐츠 없음)에 맞춰 수위를 낮게 유지한다
- 관상: 입꼬리, 미간, 눈썹, 눈두덩, 좌우 균형 다섯 가지를 바꿨을 때의 점수를 다시 계산해 효과가 큰 순으로 최대 3개를 보여 준다. 이미 강점인 자리는 권하지 않는다. 성형은 다루지 않는다
- 1.0(versionCode 1)을 내부 테스트에 올리지 않았다면 이 버전을 첫 출시로 올리고 1.0 출시 노트에 위 두 줄을 합쳐 쓴다
