## 내부 기록

- 풀이 문서(`src/report.js`): 화면에 그려진 풀이를 밝은 종이 색으로 복사해 구역마다 그림으로 바꾸고(html2canvas), 항목 경계에서 쪽을 나눠 A4 PDF로 묶는다(jsPDF). 라이브러리는 `dist/report-lib.js`로 따로 두고 처음 만들 때만 불러온다. 앱에서는 캐시에 파일을 쓰고 공유 창을 띄운다(`@capacitor/filesystem`, `@capacitor/share`). 서버로 보내지 않는다
- 예시 사주 기준 19쪽, 약 4MB. 데스크톱 크롬에서만 확인했고 실제 폰에서의 속도와 공유 창은 확인하지 못했다
- 관상 상세(`src/face-more.js`): 부위 11곳마다 뜻, 등급별 조언, 수치의 백분위
- 이메일로 직접 보내는 기능은 넣지 않았다. 서버가 필요하고, 그러면 사주와 얼굴 풀이가 기기 밖으로 나가 개인정보 고지가 달라지기 때문이다. 공유 창에서 메일 앱을 고르면 같은 일을 할 수 있다
