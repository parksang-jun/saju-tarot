## 짧은 설명 (80자 이내)

```
명리학과 관상을 겹쳐 읽습니다. 육신 분석, 10년 운과 해마다의 운세, 궁합과 타로까지 쉬운 말로.
```

## 자세한 설명 (4000자 이내)

```
등불사주는 명리학의 사주 풀이와 타로를 한 화면에서 겹쳐 읽는 앱입니다. 어두운 길에 등불 하나를 켜듯, 내 사주를 쉬운 말로 밝혀 드립니다.

■ 사주
· 절기 기준 만세력으로 년·월·일·시 네 기둥을 세웁니다. 양력, 음력, 윤달 입력을 지원합니다.
· 태어난 시는 자시부터 해시까지 열두 시로 고르고, 모르면 시 없이 봅니다.
· 오행 분포와 육신(십성) 분석: 비겁·식상·재성·관성·인성의 비율, 지장간, 육신끼리의 작용
· 신강·신약과 나에게 필요한 기운
· 10년 단위 운(대운): 지나온 운, 지금의 운, 다가올 운
· 연도를 골라 보는 해마다의 운세와 열두 달 흐름, 조심할 것
· 인생 운 그래프와 종합의견

■ 타로
· 78장 덱에서 직접 골라 한 장씩 뒤집는 3장 스프레드
· 하루 한 장, 오늘의 카드

■ 통합 리딩
· 뽑은 카드의 기운을 내 사주에 필요한 기운과 겹쳐 읽습니다.

■ 관상
· 정면 사진 한 장으로 얼굴 비율을 재서 오행형, 삼정, 오관, 십이궁을 풀이합니다.
· 나이의 자리(유년)로 올해와 앞으로 4년을 짚고, 내 사주와 겹쳐 읽습니다.
· 사진은 기기 안에서만 분석하고 저장하거나 전송하지 않습니다.

■ 궁합
· 두 사람의 생년월일로 끌림, 생활, 서로 채워 주는 힘을 점수와 풀이로 봅니다.

■ 쉬운 말 풀이
· 전문 용어 대신 쉬운 말로 풀고, 나이에 맞게 설명합니다. 명리 근거는 버튼 하나로 펼쳐 볼 수 있습니다.

■ 개인정보
· 입력한 정보는 기기 안에만 저장되고, 관상 사진은 저장하지 않습니다. 회원 가입이 없고, 화면 맨 아래에서 언제든 전부 지울 수 있습니다.

■ 유료 기능
· 기본 풀이는 무료입니다. 상세 풀이는 사주 한 명에 1,000원, 궁합 한 쌍에 1,000원입니다.
· 구독이 없습니다. 한 번 결제한 사주와 궁합은 그 기기에서 계속 볼 수 있습니다.

이 앱의 사주, 타로, 궁합, 관상 풀이와 점수는 오락·참고용입니다. 건강, 법률, 투자 등 중요한 결정의 근거로 쓰지 마세요.
```

## 데이터 보안 양식

- 데이터 수집: **예** (구매 내역)
  - 금융 정보 > 구매 내역: 수집됨, 공유 안 함, 앱 기능 목적, 필수
  - 기기 또는 기타 ID: 수집됨(RevenueCat 익명 ID), 공유 안 함, 앱 기능 목적
- 이름, 생년월일 등 입력값: 기기에만 저장되고 기기 밖으로 전송되지 않으므로 수집에 해당하지 않음
- 관상용 얼굴 사진: 기기 안에서만 분석하고 저장·전송하지 않으므로 수집에 해당하지 않음(사진 및 동영상 항목은 "수집 안 함")
- 전송 중 암호화: 예
- 데이터 삭제 요청 방법: 앱 안의 "저장된 정보 전부 지우기", 구매 내역은 문의 이메일

RevenueCat SDK가 실제로 보내는 항목은 출시 전에 RevenueCat의 Google Play 데이터 보안 안내 문서와 대조해 확인한다.
