# 등불사주 1.2 (versionCode 3)

## 플레이 콘솔 "출시 노트"에 붙여 넣을 내용

```
<ko-KR>
· 매일·매달 운세가 생겼습니다. 오늘의 운세와 이달의 운세를 점수로 보고, 달력에서 좋은 날과 조심할 날을 확인하세요
· 육신, 대운 같은 어려운 말은 제목 옆 ? 를 누르면 쉬운 말로 풀어 줍니다
· 궁합을 겉궁합, 속궁합, 살림 궁합 아홉 항목으로 자세히 봅니다
· 관상에 "이렇게 바뀌면 좋아집니다"와 분석 진행 표시가 생겼습니다
· 상세 풀이 가격은 990원입니다
</ko-KR>
```

## 내부 기록

- 매일·매달 운세: 사주 탭 맨 위. 오늘과 이번 달은 무료, 다른 날·다른 달과 날짜별 달력은 사주를 열어야 보인다. 달은 절기 기준으로 계산한다
- 용어 풀이: `src/gloss.js`의 사전 55개. 제목에 용어가 있으면 ? 단추가 자동으로 붙는다. 화면 맨 아래 "어려운 말 풀이"로 전체를 볼 수 있다
- 관상 분석 진행 막대: 엔진 불러오기, 사진 읽기, 얼굴 찾기, 풀이 만들기 단계 표시
- 가격 1,000원 → 990원. 상품 ID는 `reading_1000` 그대로(내부 이름). 실제 가격은 플레이 콘솔에서 990원으로 등록해야 한다
- 플레이 콘솔 "로그인 세부정보" 안내문의 "KRW 1,000"도 "KRW 990"으로 고친다
