# 구글플레이 출시 절차

첫 출시 범위: 안드로이드, 무료 설치 + 건당 결제(사주 1명 990원, 궁합 1쌍 990원), AI 풀이 제외.

## 1. 미리 정할 것

- [x] 앱 이름: 등불사주
- [ ] 패키지 이름 확정 (지금은 `com.parksangjun.sajutarot`, 첫 업로드 뒤 변경 불가)
- [x] 가격: 사주 1명 990원, 궁합 1쌍 990원
- [ ] 문의용 이메일
- [ ] 개인정보처리방침과 이용약관을 올릴 공개 주소 (`docs/`의 초안을 고쳐서 게시)

## 2. 계정

- [ ] 구글플레이 개발자 계정 신원 확인 완료
- [ ] 플레이 콘솔 > 설정 > 결제 프로필(판매자 계정) 생성: 유료 상품을 팔려면 필요
- [ ] RevenueCat 가입, 프로젝트 생성

## 3. 플레이 콘솔에서 앱 만들기

- [ ] 앱 만들기: 기본 언어 한국어, 앱, 무료
- [ ] 앱 콘텐츠: 개인정보처리방침 주소, 광고 없음, 콘텐츠 등급 설문, 타겟 연령(만 18세 이상 권장), 데이터 보안 양식
  - 데이터 보안: 생년월일 등 입력값과 관상용 얼굴 사진은 기기에서만 처리하고 서버로 보내지 않음. 구매 내역은 결제 처리 목적으로 RevenueCat이 처리
- [ ] 스토어 등록정보: 짧은 설명, 자세한 설명, 아이콘 512px, 그래픽 이미지 1024x500, 휴대전화 스크린샷 2장 이상
  - 설명에 "MBTI"를 쓰지 않는다(등록 상표). "성격유형"으로 쓴다
  - "오락·참고용"임을 설명에 밝힌다

## 4. 인앱 상품

플레이 콘솔 > 수익 창출 > 인앱 상품:

- [ ] 인앱 상품 `reading_1000` 생성, 가격 990원 (정기 결제가 아닌 일회성 상품). 사주와 궁합이 같은 상품을 쓴다

RevenueCat:

- [ ] 앱 추가(Google Play), 패키지 이름 입력
- [ ] 구글 서비스 계정 JSON 연결(구매 검증용)
- [ ] Products에 `reading_1000` 가져오기. Entitlement에는 연결하지 않는다(소모성이라 여러 번 살 수 있어야 함)
- [ ] Offering `default`에 패키지 하나를 만들어 `reading_1000`을 넣고 Current로 지정
- [ ] 공개 API 키(goog_...)를 `src/pay.js`의 `PAY_CONFIG.androidKey`에 넣기

가격을 바꾸려면 플레이 콘솔의 상품 가격과 `PAY_CONFIG.priceLabel`(잠금 버튼 문구)을 함께 고친다.

## 5. 빌드

준비물: Node 22, JDK 21, Android Studio(Android SDK 36).

1. 업로드 키 만들기(한 번만)
   ```bash
   sh scripts/make-keystore.sh
   cp android/keystore.properties.example android/keystore.properties   # 비밀번호 채우기
   ```
   `android/upload-keystore.jks`와 비밀번호를 안전한 곳에 백업한다. 두 파일은 `.gitignore`에 들어 있어 깃에 올라가지 않는다.
2. `src/pay.js`의 `PAY_CONFIG`에 RevenueCat 공개 키와 약관·방침 주소 넣기
3. 서명된 번들 만들기
   ```bash
   npm install
   npm run aab
   ```
   결과물: `android/app/build/outputs/bundle/release/app-release.aab`
4. 기기에서 먼저 돌려 보려면 `npm run apk`(디버그 APK) 또는 `npm run android`(Android Studio)
5. 다시 올릴 때마다 `android/app/build.gradle`의 `versionCode`를 1씩 올린다

GitHub에서 빌드하려면 저장소 시크릿 네 개(`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`)를 넣고 Actions의 "Android release bundle"을 실행한다.

아이콘과 스플래시는 `npm run assets`로 다시 만든다. 스토어 문구와 설문 답변은 `docs/store-listing.md`.

## 검토용 열람 코드

- 구글 검토자는 결제를 할 수 없으므로, 화면 맨 아래 "열람 코드"에 코드를 넣으면 그 기기에서 유료 풀이가 모두 열린다.
- 코드는 저장소에 두지 않고 SHA-256만 `src/pay.js`의 `reviewHash`에 둔다. 코드는 플레이 콘솔 > 앱 콘텐츠 > 로그인 세부정보에 적어 둔다.
- 코드가 새면 `printf '%s' '새코드' | shasum -a 256` 결과로 `reviewHash`를 바꾸고 콘솔의 안내도 함께 고친다(영문 대문자와 숫자, 하이픈만 사용).
