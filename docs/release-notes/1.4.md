## 내부 기록

- 오늘의 운세는 열기 전에 내용을 전혀 보여 주지 않는다. 무엇을 볼 수 있는지 적힌 단추 하나만 둔다
- 이달의 운세 탭과 날짜별 달력을 없앴다(1.2~1.3에 있던 것). 월별 흐름은 유료 상세 풀이 안에 그대로 있다
